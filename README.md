# Magaz Gift

Кликабельный прототип корзины магазина мерча Авиасейлс с анимацией появления подарка.

- В корзине три товара, список скроллится, блок «Итого» закреплён снизу.
- «+» увеличивает количество; при 2+ штуках иконка корзины в степпере меняется на «−».
- Сумма в карточке и в «Итого» пересчитывается.
- При сумме от 20 000 ₽ появляется подарок: 0,6 с, карточка выезжает из-за верхней карточки, сдвигая остальные вниз, через scale и opacity. Если сумма падает ниже порога, подарок прячется обратной анимацией.
